PostService

Версія 1.0

Вебзастосунок «Облік поштових відправлень»: перегляд списку, створення, редагування та видалення відправлень.

Застосунок отримує й змінює дані через REST API сервісу PostService.

Інтерфейс адаптивний: зручний на широкому моніторі та на екрані смартфона.
